# Reporting Preferences

## Lennox Shipping Daily Report

When preparing the daily shipping report for **LENNOX INDUSTRIES INC.** (`ORG-754962`) at **Valley View / LT_F1**, provide the complete report together from the start.

Required fields:

- DN / Order number
- Load number
- Status
- Appointment date and time
- Dock
- Load task
- Assignee
- Carrier
- Equipment / trailer
- Seal
- Pallets by DN/load
- Cartons / boxes by DN/load
- Grand total pallets
- Grand total cartons / boxes

Do not provide the operational status first and the pallet/carton totals separately later. The report should include both detail and totals in one response.
